L'arbre du diagramme

Le panneau Arbre du diagramme (F10 pour l'afficher ou le masquer) liste tous les objets du diagramme. Cliquer sur une entrée sélectionne la forme correspondante sur le canevas ; Maj/Ctrl+clic construit une sélection multiple ici de la même façon que sur le canevas, ce qui peut être un moyen pratique de sélectionner plusieurs formes qui se chevauchent pour Grouper (Ctrl+G).

Lorsqu'une ou plusieurs lignes sont sélectionnées, Ctrl+Haut / Ctrl+Bas modifie la position d'empilement de l'élément sélectionné.

Menu contextuel (clic droit)

  • Localiser – sélectionne cette forme et fait défiler le canevas jusqu'à elle.
  • Propriétés – ouvre sa boîte de dialogue Propriétés (pour les types de formes qui en possèdent une).
  • Masquer ce type (…) – masque de l'arbre tous les objets de ce même type, afin de raccourcir la liste lorsque vous travaillez sur un type de forme précis.
  • Afficher le type d'objet – un sous-menu listant tous les types actuellement masqués de cette façon, pour en rétablir un.

Editing and Selecting

The Edit menu

  • Undo / Redo – Ctrl+Z / Ctrl+Shift+Z. Every open diagram has its own independent undo history.
  • Copy / Cut / Paste – Ctrl+C / Ctrl+X / Ctrl+V. You can paste into a different diagram tab than the one you copied from.
  • Clone – Ctrl+B, opens a copy of the whole current diagram in a new tab.
  • Duplicate – Ctrl+D, a quick copy-and-paste of the current selection in one step.
  • Delete – the Delete key, removes the current selection.

The Select menu

Beyond clicking shapes directly (Shift/Ctrl-click to add to the selection, or drag a rubber-band box around several at once), the Select menu offers:

  • All (Ctrl+A) / None – select everything on the current layer, or clear the selection.
  • Invert (Ctrl+I) – swap selected and unselected shapes.
  • Same Type – extends the selection to every other shape of the same type as what's currently selected.
  • Transitive – extends the selection outward along connected lines, following the chain of connections as far as it goes.
  • Connected – extends the selection to shapes directly connected to the current one(s) by a line, one hop only.

The Diagram Tree panel also supports Shift/Ctrl-click multi-selection, which can be a convenient way to build up a selection for Group when shapes overlap on the canvas – see The Diagram Tree.

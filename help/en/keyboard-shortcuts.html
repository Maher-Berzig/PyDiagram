On the canvas

ShortcutAction
SpaceToggle between the Select tool and whichever drawing tool was last used
EscapeCancel the shape currently being drawn, or switch back to the Select tool
Ctrl+click a shapeOpen its Properties dialog (Text is the exception: double-click enters text editing instead, so use right-click there)
Arrow keysNudge the selected shape(s) by a small step
Shift + Arrow keysNudge the selected shape(s) by a larger step (10×)
Ctrl+Up / Ctrl+DownBring Forwards / Send Backwards the selected shape(s) (in the Diagram Tree, they reorder the selected item's stacking position instead)

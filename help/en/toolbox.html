The Toolbox and Drawing Shapes

The Shapes dock on the left is PyDiagram's toolbox. From top to bottom it holds: a small grid of general tool modes, a shape-category dropdown, a grid of shape buttons for whichever category is selected, and a panel of default drawing properties.

Tool modes

  • Select – the default mode. Click a shape to select it, drag it to move it, or drag one of its handles to resize it. Press Space at any time to jump back to Select.
  • Zoom – scroll the mouse wheel over the canvas to zoom in or out.
  • Pan – drag with the left mouse button to move the canvas around.
  • Anchor – select a shape first, then click on it to add a new connection point of your own; see Connecting shapes with lines.

Shape categories

The dropdown switches between:

  • Basic – Rectangle, Ellipse, Plot (a math function graph), Polygon, Beziergon, Line, Arc, Polyline, Zigzagline, Bezierline, Image, Text.
  • Flowchart – Process, Decision, Database, Data (I/O), Predefined Process, Preparation, Document, Delay, Summing Junction.
  • UML – Class, Interface, Actor, Package, Component, Node, Note, Lifeline, Required Interface.
  • Assorted – Square, Circle, Regular Polygon, Star, Spiral, Three-Quarter Circle, Crescent, Spring, L-shape, Isosceles Triangle, Right Triangle, Cross.
  • Any categories of your own, saved via Objects > Save as New Shape... – see Custom shapes.

Click a shape's button to select that drawing tool, then click-and-drag on the canvas to draw it at the size you want. After placing one shape, PyDiagram automatically switches back to the Select tool, ready to place the next one.

Default drawing properties

The panel at the bottom of the Shapes dock sets the fill and border color, line width, line style, and start/end arrow style that new shapes are drawn with – it never changes shapes already on the canvas. It includes a Restore default colors button and a Reverse colors button (swaps foreground and background) alongside the two color swatches.

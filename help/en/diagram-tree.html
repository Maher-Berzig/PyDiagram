The Diagram Tree

The Diagram Tree panel (F10 to show/hide it) lists every object in the diagram. Clicking an entry selects the matching shape on the canvas; Shift/Ctrl-click builds up a multi-selection here the same way it does on the canvas, which can be a convenient way to select several overlapping shapes for Group (Ctrl+G).

With one or more rows selected, Ctrl+Up / Ctrl+Down reorders the selected item's stacking position.

Right-click menu

  • Locate – selects and scrolls the canvas to that shape.
  • Properties – opens its Properties dialog (for shape types that have one).
  • Hide this type (…) – hides every object of that same type from the tree, to cut down the list while working on a specific kind of shape.
  • Show object type – a submenu listing every type currently hidden this way, to bring one back.

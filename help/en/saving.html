Saving and Exporting a Diagram

Saving

Choose File > Save (Ctrl+S) to save the diagram to its .pydia file – the first time, this asks where to save it. File > Save As... (Ctrl+Shift+S) always asks, saving a copy under a new name or location without touching the original file.

File > Save All saves every open diagram that has unsaved changes, in one step and in tab order. A diagram that already has a file is written straight to it; one that was never saved asks where to save it, suggesting its tab name. Cancelling one of those prompts stops Save All at that point – diagrams already saved stay saved. Save All is also in the toolbar's Save drop-down.

A .pydia file keeps everything about the diagram: every shape and its properties, connections between shapes, layers, and canvas settings – reopening it (see Opening a diagram) restores the diagram exactly as it was saved.

Exporting

The File menu also offers four ways to export the current diagram (or diagrams) for use outside PyDiagram:

  • Export as PNG... – a bitmap image of the diagram.
  • Export as SVG... – a scalable vector image, editable in other vector drawing programs.
  • Export to PDF... – a small dialog lists every diagram tab currently open, each with a checkbox; check the ones to include, use Move Up / Move Down to set their page order, then Export to write them all into one multi-page PDF file.
  • Export as Tikz... – LaTeX/TikZ source code for the diagram, shown in a popup window with Copy to Clipboard and Save As... buttons – handy for including a diagram directly in a LaTeX document. The same window opens from the toolbar's Tikz button.

Unlike Save, none of the four exports above change the diagram's own .pydia file or its Save/Save As state – export as many times, and in as many formats, as needed.

PDF links

When several diagrams are exported to one PDF, any shape can act as a clickable link to another diagram's page. Open the shape's Properties dialog (Ctrl+click it, or select it and press Alt+Return; for Text, right-click and choose Properties) and choose a diagram in the PDF Link list at the bottom. The list holds None plus every other diagram currently open in a tab, shown by file name.

Then use File > Export to PDF...: each shape that has a link becomes an invisible clickable area covering the shape, and clicking it in a PDF viewer jumps to the page of the destination diagram. A few things to know:

  • The destination diagram must be checked in the Export to PDF list. Otherwise the export stops with a message asking you to include it.
  • A link follows the diagram, not a page number: reordering pages with Move Up / Move Down never breaks it.
  • The link is saved in the .pydia file and is kept by Copy, Paste and Duplicate. Save the destination diagram too, so that its identity is stored in its own file.
  • If the destination is no longer open, the list shows Unavailable destination (document is closed) and the link is kept; open the destination again to use it.
  • Links exist only in the PDF export – the shape looks the same, and PNG, SVG and Tikz exports do not contain links.
  • When running PyDiagram from source, the pypdf package must be installed (pip install pypdf).

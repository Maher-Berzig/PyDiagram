Arranging Objects

The Objects menu (also reachable via the toolbar) works on the current selection.

Stacking order

The four stacking commands are also grouped in one drop-down button on the toolbar (the icon with an up arrow and a down arrow).

  • Send to Back (Ctrl+Shift+B) / Bring to Front (Ctrl+Shift+F)
  • Send Backwards (Ctrl+Down) / Bring Forwards (Ctrl+Up) – move one step at a time instead of all the way. While the Diagram Tree has the keyboard focus, Ctrl+Up / Ctrl+Down instead reorder the selected tree item; see Diagram tree.

Grouping

  • Group (Ctrl+G) – combines the selected shapes into a single object that moves, resizes and rotates as one.
  • Ungroup (Shift+Ctrl+G) – splits a group back into its individual shapes.

Align

With two or more shapes selected, the Align submenu offers Left, Center, Right, Top, Middle, Bottom, Spread Out Horizontally, Spread Out Vertically, Adjacent, and Stacked – each with its own Shift+Alt+… shortcut (see Keyboard shortcuts for the full list).

Rotate, Flip and Scale

  • Rotate... – opens a dialog to rotate the selection by an exact angle, as one rigid group.
  • Ctrl+R / Ctrl+Shift+R – nudge the selection by +1° / −1° without opening a dialog.
  • Flip > Horizontal (Ctrl+Shift+H) / Vertical (Ctrl+Shift+V).
  • Scale – Ctrl+L / Ctrl+Shift+L nudge horizontal scale by +1% / −1%, and Ctrl+M / Ctrl+Shift+M do the same vertically.

Other

  • Properties (Alt+Return) – opens the selected shape's Properties dialog; see Shape properties.
  • Save as New Shape... – saves the current selection into your own shape library; see Custom shapes.

Opening a Diagram

Choose File > Open... (Ctrl+O) and pick a .pydia diagram file. It opens in a new tab, alongside whatever is already open – so you can, for example, copy a shape from one diagram into another.

The file picker allows selecting several files at once (Ctrl+click or Shift+click); each selected .pydia file opens in its own tab. A file that cannot be opened reports its own error and does not stop the others.

To start a blank diagram instead, choose File > New (Ctrl+N); it also opens in its own new tab.

Each open diagram has its own tab along the top of the window, its own undo history, and its own set of layers. Closing a tab that has unsaved changes asks for confirmation first.

Colors, Gradients and Patterns

Every fill/border color swatch in PyDiagram – in a shape's Properties dialog, in the toolbox's default-properties panel, or in Diagram Properties – opens the same picker when clicked, with a choice of three kinds of fill:

Solid Color

The ordinary color picker, alpha channel (transparency) included.

Gradient...

A two-color gradient between a Start Color and an End Color, in one of two shapes, chosen with the Linear / Radial buttons at the top of the dialog:

  • Linear – the color changes along a straight line across the shape. Set the exact angle with the Direction spin box, or click one of the eight arrow buttons below it for a common direction (left-to-right, top-to-bottom, diagonals, and so on).
  • Radial – the color spreads outward from a single point, starting at the point (Start Color) and fading to End Color at the shape's farthest edge. The point starts at the shape's center; click or drag anywhere on the preview strip at the top of the dialog to move it – the gradient recenters live as you drag, and stays wherever you leave it.

The preview strip at the top always shows the gradient as it will actually look. A gradient automatically resizes to fit whatever shape it's filling, so it still looks right if you resize the shape afterwards.

Pattern...

A repeating tile fill, with:

  • Pattern – one of several built-in hatch/dot patterns, or Image... to use a picture file of your own as the repeating tile instead.
  • Pattern Color / Background Color – the two colors of a built-in pattern.
  • Pattern Size and Line Width – how large each tile is, and how thick its lines are.
  • Image File, Tile Width and Tile Height – shown instead of the above when Image... is chosen: browse to a picture and set the size of each repeated tile.
  • Pattern Angle – rotates the whole tiling.

Whichever kind of fill a shape ends up with, its swatch button always shows a small preview of the actual result, and reopening the picker later shows the Gradient or Pattern dialog prefilled with whatever was set before – including a radial gradient's control point, right where you left it.
